# My Stardew Prototype

Prototipe awal game *top-down* 2D bergaya *farming/adventure* yang dirancang untuk layar sentuh HP dan rencana dikemas menjadi APK Android.

## Fitur & Pengaturan Saat Ini
* **Kontrol:** *Tap-to-move* langsung di layar sentuh (tanpa tombol fisik/virtual di layar).
* **Grafik:** Berbasis HTML5 `<canvas>` dengan resolusi internal `320x180`, *tile grid* `16x16`, dan *pixel rendering* tajam.

## Struktur Folder
```text
my-stardew-prototype/
├── index.html
├── style.css
├── game.js
└── assets/
```
